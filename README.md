# نموذج موقع ديوان شعري — GitHub Pages

هذا نموذج عربي باتجاه RTL، بتصميم أدبي داكن ولمسات ذهبية. جميع الأسماء والنصوص بين الأقواس مربعة هي بيانات تجريبية يجب استبدالها.

## الملفات
- `index.html`: الصفحة الرئيسية ومعلومات المؤلف والكتاب.
- `styles.css`: التصميم.
- `assets/cover.svg`: غلاف تجريبي قابل للاستبدال.
- `assets/favicon.svg`: أيقونة الموقع.
- `book.pdf`: أضف نسخة PDF من الكتاب بهذا الاسم إذا أردت زر التحميل أن يعمل.

## النشر على GitHub Pages
1. سجّل الدخول إلى https://github.com وأنشئ مستودعاً جديداً (Repository)، مثلاً `poetry-book`.
2. ارفع جميع ملفات هذا المجلد إلى المستودع، مع الحفاظ على المجلد `assets`.
3. من المستودع افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر حتى ينشر GitHub الموقع. سيكون العنوان غالباً:
   `https://YOUR-USERNAME.github.io/poetry-book/`

## قبل النشر
- استبدل `[اسم المؤلف]` و`[اسم الكتاب]` وسائر النصوص التجريبية في `index.html`.
- استبدل `assets/cover.svg` بغلاف الكتاب. إذا استخدمت صورة باسم مختلف، حدّث مسار الصورة في `index.html`.
- أضف ملف `book.pdf` إلى جذر المستودع، أو غيّر رابط التحميل إلى رابط PDF عام.
- عدّل وصف الصفحة وبيانات التواصل.
- لا تنشر الكتاب إلا إذا كنت تملك حقوق نشره أو إذن النشر.

## الظهور في Google
بعد النشر:
1. أضف عنوان الموقع إلى Google Search Console.
2. استخدم فحص عنوان URL ثم اطلب الفهرسة.
3. اجعل اسم المؤلف الكامل واضحاً في عنوان الصفحة والوصف والعناوين ومحتوى السيرة.
4. الفهرسة والترتيب غير مضمونين، وقد يستغرق ظهوره وقتاً. البحث باسم المؤلف وحده يعتمد أيضاً على شهرة الاسم ومحتوى الويب المنافس.

هذا النموذج لا يحتوي على تحليلات أو نماذج تجمع بيانات الزوار.
